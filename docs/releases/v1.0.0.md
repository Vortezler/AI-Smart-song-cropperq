First release of **Smart Music Cropper**: an offline Android app that finds where the music actually ends in a track and trims the trailing silence / dead air.

### What's in v1
- Pick one MP3 or WAV (up to 20 minutes) with the system file picker.
- An on-device YAMNet model (TensorFlow Lite) listens to the last minute and suggests the cut point.
- Waveform of the ending with a draggable cut line, ±0.1 s nudge buttons and a live "Trimming last X.Xs" label.
- Export as AAC in an `.m4a` file, either as a new `<name>_cropped.m4a` or overwriting the original (Settings).
- Fully offline: the app has no network permission.

### Install
Download `SmartMusicCropper-v1.0.0.apk` below and open it on an Android 8.0+ device (allow installs from your browser/file manager when asked). The APK is signed with a debug key: it's a working build, not a Play Store release.

### Known limitations
- Output is always `.m4a` (Android has no built-in MP3 encoder).
- Only trailing silence is detected; no start-of-track or mid-track trimming, no batch mode.
- MP3, WAV input only.
